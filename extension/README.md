# NetConfirm Browser Extension

Instantly check any news article for misinformation directly from your browser using NetConfirm AI.

## Install from Microsoft Edge Add-ons Store

1. Open Microsoft Edge
2. Go to the [NetConfirm Edge Add-on](#) *(link added after publishing)*
3. Click **Get** then **Add extension**
4. The NetConfirm icon will appear in your toolbar

> Chrome users: Edge extensions work in Chrome too.
> Go to `chrome://extensions`, enable **Allow extensions from other stores**, then install from the Edge store link above.

---

## Manual Install (Chrome / Edge / Brave)

1. Download and extract this repository
2. Go to `chrome://extensions` (or `edge://extensions`)
3. Enable **Developer Mode** (top right toggle)
4. Click **Load unpacked**
5. Select the `extension/` folder
6. The NetConfirm icon appears in your toolbar

---

## Manual Install (Firefox)

1. Go to `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on**
3. Select `extension/manifest.json`

---

## Setup

1. Click the NetConfirm icon in your toolbar
2. Click **⚙️ Settings**
3. Enter your **API Key** — get one free from the [NetConfirm app](https://netconfirm.onrender.com) under the API tab
4. Save settings

---

## How It Works

1. Navigate to any news article
2. Click the NetConfirm extension icon
3. Click **Analyse This Page**
4. Get an instant FAKE or REAL verdict with confidence score and signal breakdown
5. Click **Open Full Analysis** to see the full SHAP explanation in the app

---

## Features

- Auto-extracts article text from any news page
- Detects language and shows a badge if translated
- Confidence gauge and signal breakdown in the popup
- Configurable API key, API URL, and app URL
- API key stored securely in browser storage
